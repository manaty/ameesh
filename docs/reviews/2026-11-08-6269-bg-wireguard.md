**B.1 — delta (v5, forme mesh-design #200139), iptables seul, aucun paquet installé :**
- **INPUT** : chaîne dédiée `BG-IN`, sautée en tête (`-I INPUT 1 -i wg0 -s 10.77.0.6/32 -j BG-IN`) ; dans `BG-IN` : `-d 10.77.0.1/32 -p tcp --dport 5432 -j ACCEPT`, puis `-j DROP`. Aucun accept `established` (les réponses de Postgres sortent par OUTPUT).
