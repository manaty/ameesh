### A. BG (bureau, root), après deux avis hors claude — STOP au premier échec, aucun écrasement
```sh
(
  set -euo pipefail; umask 077
  for f in /etc/wireguard/ameesh.key /etc/wireguard/ameesh.pub /etc/wireguard/ameesh.conf; do
    [ ! -e "$f" ] || { echo "STOP : $f existe déjà"; exit 2; }; done
  ip -4 addr | grep -q '10\.77\.' && { echo "STOP : une adresse 10.77 existe déjà sur BG"; exit 2; }
  apt-get install -y --no-install-recommends wireguard-tools
  install -d -m 700 /etc/wireguard
  wg genkey > /etc/wireguard/ameesh.key            # privée jamais affichée
  wg pubkey < /etc/wireguard/ameesh.key > /etc/wireguard/ameesh.pub
  cat > /etc/wireguard/ameesh.conf <<'C'
[Interface]
Address = 10.77.0.6/32
PostUp = wg set %i private-key /etc/wireguard/ameesh.key

[Peer]
PublicKey = GUovIgGkqLAj2d2stwWet4weM4ySzKmRZqXd/bXwElU=

  chmod 600 /etc/wireguard/ameesh.key /etc/wireguard/ameesh.conf; chmod 644 /etc/wireguard/ameesh.pub

```
L'interface n'est **pas** montée avant l'étape B. Seule `ameesh.pub` (publique) est transmise à l'owner.

### B. Concentrateur (owner, root sur manaty-mesh-1) — en deux temps, relu entre les deux

**B.1 Geste (owner), seulement après B.0 relu :**
1. Pare-feu (si nftables) : fichier dédié `/etc/nftables.d/ameesh-bg.nft`, inclus par le fichier chargé au boot (relevé B.0) :
```
table inet ameesh_bg {
  chain input   { type filter hook input   priority -10; policy accept;
    iifname "wg0" ip saddr 10.77.0.6 ip daddr 10.77.0.1 tcp dport 5432 counter accept
    ip saddr 10.77.0.6 counter drop }
  chain forward { type filter hook forward priority -10; policy accept;
    ip saddr 10.77.0.6 counter drop
    ip daddr 10.77.0.6 counter drop }

```
   Sémantique : le `drop` est final ; l'`accept` de cette table ne l'est pas (une chaîne ultérieure peut encore rejeter le 5432 — cela casserait la fonction, pas la sécurité : à vérifier par le test C.2). Chargement : `nft -c -f /etc/nftables.d/ameesh-bg.nft` puis `nft -f /etc/nftables.d/ameesh-bg.nft`, relecture `nft list table inet ameesh_bg`. **Pas de `systemctl restart nftables`** sauf preuve (`nft -c -f` du fichier de boot complet) qu'il contient tout le ruleset courant. Si iptables est l'outil en place : règles équivalentes en tête de INPUT/FORWARD + `netfilter-persistent save`, à relire.
