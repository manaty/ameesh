Patch release of the 11:00 cut of 16/10/2026 (build/beta rhythm, canon §11 bis, hourly batches home#94). It brings 103 lots merged in five scripted batches: #1362 (49 lots), #1365 (6 lots), #1372 (6 lots), #1389 (12 lots) and #1405 (30 lots). Four additive migrations: 0441, 0447, 0451, 0452.

**Process workflows (TPK consumer contract, manaty/ameesh#1379)**
- Slice A (#1918): strict native compiler for Process workflows, with refusal tests.
- Slice B (#1922): native revision/stage registry with idempotent transactional receipts (migration 0452). The public API (docs/design/process-workflow-registry.md) takes no caller-supplied verifier. An unavailable verifier refuses. An identical replay returns the same receipt, and a changed payload under the same key is a conflict. A revoked actor or stale authority epoch gets nothing back. `work move`, `work close`, merge declaration and dependency release refuse a lot pinned to a workflow, also through a mediated executor (no raw SQL). The new columns stay closed to the supervisor role until they are classified.
- Slice C (#1924): finite installed verifiers (14 guards, 7 opt-in types) that judge on real evidence read by the server inside the transaction, with a fail-closed capability report.
- B and C each passed two independent reviews (Codex and Claude) after their fixes. Everything is opt-in: no consumer activation in this release.

**Fleet health**
- The runner now reaps its git processes (#1749): on 16/10 the hosts carried 5,900, 11,000 and 6,200 `git <defunct>` zombies, which raised the load and paused agents.
- One identity per agent or role on GitHub instead of the owner's token (#1645).
- `ci_parts` keeps `LD_LIBRARY_PATH` for the selector: Actions Python crashed (SIGSEGV) without it (#1938).
- Staging: `vm.sh` accepts a server explicitly without executor (empty `PERSONAS_VM`, #1928).
- Codex accounts: an account in overage is never a candidate, which ends the primary ↔ secondary failover loop of 16/10 at 03:13 (#1883, migration 0451: an account's identity is the fingerprint of the folder it reads).
