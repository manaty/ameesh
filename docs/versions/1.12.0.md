**Lots, reviews and the reviewer-list upgrade**
- Designating a reviewer now **adds** the name to the lot's reviewers instead of replacing the previous designation (#2076, migration 0456). `work show` and the JSON `reviewers` field keep every designated name, and the wait and alerts name each reviewer whose verdict on the frozen head is still due. `ameesh work reviewer <id> <agent> --remove` withdraws one designation.
- **Upgrade note — older runners.** A runner that predates this change still writes the legacy `reviewer` field as if it replaced the designation. Migration 0456 turns that write into an addition, so a lot that already had a reviewer keeps that reviewer when an old runner designates another one. Withdraw a name explicitly with `ameesh work reviewer <id> <agent> --remove` (or upgrade the runner). Assigning or delegating the lot to a reviewer still removes that person's designation, and the journal now names every reviewer removed this way.
