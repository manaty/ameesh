Minor version after the 1.11.5 patch cut of 17/10/2026. It brings the h-1200 package (16 units) and the h-1600 package (16 lots), plus #2217, #2259, #2271 and #2238 merged directly. Five additive migrations: 0438, 0442, 0445, 0456 and 0460.

**Lots, reviews and the reviewer list**
- Designating a reviewer now **adds** the name to the lot's reviewers instead of replacing the previous designation (#2076, migration 0456). `work show` and the JSON `reviewers` field keep every designated name, and the wait and alerts name each reviewer whose verdict on the frozen head is still due. `ameesh work reviewer <id> <agent> --remove` withdraws one designation. The journal names every reviewer removed by an assignment or delegation (#2084).
- **Upgrade note — older runners.** A runner that predates this change still writes the legacy `reviewer` field as if it replaced the designation. Migration 0456 turns that write into an addition, so a lot that already had a reviewer keeps that reviewer when an old runner designates another one. Withdraw a name explicitly with `ameesh work reviewer <id> <agent> --remove` (or upgrade the runner). Assigning or delegating the lot to a reviewer still removes that person's designation.
- Designating a reviewer of the same model family as the author now raises a warning instead of being silently accepted (#800). A designated reviewer without a lot of their own is counted as idle for capacity and pickup (#1726). A review lot names the freeze actor it discards and reads the holders from the journal (#1859).
- A manual merge outside the queue now opens the post-merge review lot (#1104, migration 0438), so a merge that bypasses the queue no longer escapes review. The Claude review of the #1465 provenance work is closed by its N (#1534).

**Merge queue, fire and release**
- `ci run --full` no longer waives the required review opinions (#2214): the "review before CI" rule stops depending on a convention.
- The fire now requires the target's required checks on the frozen head, with their exact names from end to end; the required-check source is read on that exact head, and an abbreviated freeze names the same head (#2271). This closes the case where a merge escaped without a real full suite (#2255).
- The conflict radar no longer repeats a notice while a conflict's inputs are unchanged (#2238).
- The SLO "reassign now" alert no longer fires just after a pickup or a reassignment: the new holder has a 30-minute grace period (#2217). An SLO alert also stops prescribing a reassignment when the blocker is not the holder (#2231).
- A merge title that cites `#N` inside a removal phrase ("without #598", "except #N", a postponed negation) no longer marks lot N as merged (#2259).
- A new packet train composes, validates and merges reviewed lots every hour (#1467, migration 0442). `rebase-lot` keeps the #1669 controls (lot prefix, conflict markers) when the state names another version (#2186).

**Runner, sessions and accounts**
- A finished lot turn no longer shares its session with another open lot (#2055); parking a lot writes the exact journal, thread and brief when nothing was actually parked (#2242).
- The resident Claude `argv()` is idempotent: a second call no longer switches to `--resume` with the new id (#2008).
- Executors reread the account configuration instead of keeping an expired budget ceiling, and the start options distinguish the file and inherited profiles (#1466).
- Automatic pickup uses the 30-day attribution history without excluding almost every idle agent (#1739). A human/pilot hold without a date can no longer extinguish the stale-lot reminder (#1664).
- `paused_on_budget` is exposed in `agent_detail`, the `progress.paused_on_budget` alias is kept, and the #1070 review findings are applied in English (#1186).
- A mute profile is refused when the server requires nothing, and the private profile's scope is documented (#2197).
- The full-pipe path has a deterministic witness (#2090).

**Hosts, housekeeping and updates**
- Housekeeping follows the resolved common directory of worktrees (#2180): untracked clones, unregistered worktrees and stale "gone" entries are discovered instead of being invisible. A skipped CLI pass now says "executed" or "nothing to do" instead of displaying a misleading success (#2173).
- Console scripts added by a future version no longer leak into the stable venv (#2155), and pip's `/bin/sh` shebang wrapper is accepted when the venv path exceeds 127 characters (#2156).
- The operator pause is no longer presented as available in `show`, `projects` and `idle_capacity` (#2200). `notify.run_pass` uses the declared thresholds instead of an observed perimeter that may differ (#2105).
- Lease renewal makes its last retry at mid-margin during a database outage, with a guard on the BailTest duration (#2172). The `lock_timeout` witnesses are robust under load (5 s → 30 s) and the row-lock documentation is updated (#920).
- Migration 0460 recreates `agent_mesh_overview` with explicit `runner_seen_*` columns and preserves the existing ACLs (#2229), so the supervisor role contract holds on databases created before migration 0411.
- The operator tarball documentation describes paths without symbolic links (#1578).

**Measurement, CI and map**
- The map measurement ignores `SIGTERM` while its output is being written, so a stopped bridge no longer leaves a zero-byte coverage file (#2225).
- A map part that exceeds the 40-minute ceiling no longer returns a zero map: the ceiling is 60 minutes and the plan flags tight parts through `--plafond-min` (#2224).
- The test plan no longer treats a nested walrus as a false import proof (#2098). The CLI roadmap review suites N1–N3 are covered (#2185).

**Upgrade notes**
- The five migrations are additive only: 0438 (post-merge review lot), 0442 (packet train), 0445 (provenance receipts), 0456 (reviewer list) and 0460 (overview columns). No destructive change is required.
- After the migrations, check that the overview exposes `runner_seen_at`, `runner_seen_host` and `runner_seen_owner` on existing databases, not only on fresh ones; `ameesh doctor` and the supervisor role contract read them.
